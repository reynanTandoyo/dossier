## Decision

A session is the session of a worker when the environment variable DOSSIER_ROLE is `worker`; whoever starts the worker sets it. Any other value, or none, is the session of a planner and behaves as before. In a worker session `dossier brief` without --task prints one line in place of the project brief (`--full` prints the brief), and the hook after todo commands prints the entries for a claimed task but nothing after `todo done` and `todo stuck`. The planner runs `review-task` for a task a worker finished and records what its note says. (Owner, 2026-11-26.)

## Reason

The brief at session start costs about 1,500 tokens that a worker with a complete work order does not need; after todo claim the hook already gives it the entries for its own task. An environment variable works with every agent program and needs no change to the installed hooks, so an upgrade needs only the new program and one command.

## Rejected

A separate hook command for the session start: every project would have to install its hooks again. A list of worker names in the settings: names are chosen freely by whoever starts a worker.
