## Decision

A rule for agents that a `todo` command can trigger is carried out by a Claude Code hook and not left to the agent's memory: after a task is claimed, finished or given back, a hook prints what `dossier` has for that moment. The hook only reads the `todo` command that was run; it changes no task (D38). (Owner, 2026-11-22.)

## Reason

A rule in a text is followed only some of the time; a hook runs every time. (Idea taken from the ECC project.)
