# Glossary of DOSSIER

## entry

- meaning: One Markdown file in the dossier: a decision, assumption, finding, lesson, how-to, tool, usage record, investigation or digest.
- history: 2026-11-25T07:34:45+01:00 reyna via reyna - claude: added

## draft

- meaning: An entry an LLM concluded on its own; it counts as knowledge only after a person approves it.
- history: 2026-11-25T07:34:45+01:00 reyna via reyna - claude: added

## digest

- meaning: An entry that sums up a closed milestone; brief and status show it in place of the entries it covers.
- history: 2026-11-25T07:34:45+01:00 reyna via reyna - claude: added

## investigation

- meaning: An entry that records one problem, the attempts to solve it in order, and what solved it.
- also: INV
- history: 2026-11-25T07:34:45+01:00 reyna via reyna - claude: added

## take

- meaning: Recording who works on a large file and for which task, before it is copied to a PC and returned.
- history: 2026-11-25T07:34:45+01:00 reyna via reyna - claude: added

## connected folder

- meaning: A folder on a PC linked to a project on the server; dossier commands typed there run on the server.
- history: 2026-11-25T07:34:45+01:00 reyna via reyna - claude: added

## team dossier

- meaning: The dossier shared by all projects: lessons, how-tos, tools and the glossary, without customer data.
- history: 2026-11-25T07:34:45+01:00 reyna via reyna - claude: added

## level

- meaning: The difficulty of a todo task, 1 to 5; a level-1 task lists its files, steps and check, so the weakest worker can do it.
- history: 2026-11-25T07:34:45+01:00 reyna via reyna - claude: added

## LLM

- meaning: A large language model working in a session, such as Claude; what it concludes on its own is a draft until a person approves it.
- history: 2026-11-25T07:35:04+01:00 reyna via reyna - claude: added
